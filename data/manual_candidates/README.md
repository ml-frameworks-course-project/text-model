# Подборка текстов для разметки

Подборка содержит 150 примеров для ручного обогащения PromptShield. Разметчикам передаётся файл `annotation_input.jsonl` без исходных меток, чтобы каждый самостоятельно определил, содержит ли текст промпт-инъекцию.

Скрипт отбора создан 15 ноября 2026 года с помощью ИИ ChatGPT. В тот же день выборка пересобрана: оставлены англоязычные тексты и усилена проверка похожих примеров.

## Источники

- [NotInject](https://huggingface.co/datasets/leolee99/NotInject): 65 примеров; лицензия MIT; дата обращения: 15.11.2026.
- [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections): 85 примеров из train; лицензия Apache-2.0; дата обращения: 15.11.2026.

Исходные идентификаторы и сведения о лицензиях находятся в `provenance_private.jsonl`.

До завершения независимой разметки не передавайте разметчикам `provenance_private.jsonl`, `selection_stats.json`, `stable_id_map.json` и `collect_candidates.py`. В них есть предварительные метки или параметры отбора. Итоговые метки определяются при ручной разметке.

## Воспроизведение

Для запуска нужны Python, пакеты `requests` и `langdetect==1.0.9`, а также доступ к Hugging Face:

```bash
pip install requests langdetect==1.0.9
python collect_candidates.py
```

Перед запуском измените переменную `OUT` в начале скрипта. Укажите путь к новой папке, которая ещё не существует: скрипт не перезаписывает существующую папку с результатами.

Язык определяется библиотекой `langdetect` с seed `52`. При ручной проверке обнаружены смешанные и неанглоязычные записи, которые исключены по номерам строк источника. Записи с буквами нелатинских алфавитов также исключаются. Автоматическое определение языка может ошибаться, особенно на коротких и смешанных текстах. Таблица `stable_id_map.json` сохраняет идентификаторы ранее отобранных записей, которые остались в выборке.

При отборе использован seed `52` и предварительное соотношение классов 93 к 57. Версии источников и PromptShield указаны в переменной `SHAS`. PromptShield загружается по закреплённой версии, а остальные записи получаются через Dataset Viewer API. Скрипт проверяет ревизии этих источников до и после загрузки и останавливается, если они изменились. Итоги отбора сохранены в `selection_stats.json`.

В обновлённой выборке 64 текста сохранили прежние идентификаторы, для 86 идентификаторов текст заменён. Ранее импортированные данные в doccano нужно обновить; уже сделанные ответы и заметки следует сохранить и сверить по `id` и полному тексту.

## Проверка пересечений

Точных совпадений и вхождений текстов длиной от 40 символов с train, validation и test PromptShield не обнаружено. После отбора дополнительно проверена похожесть по множествам слов с порогом 0,75 для текстов не короче пяти разных слов: совпадений с PromptShield не обнаружено. Внутри подборки нет пар с посимвольной похожестью от 0,75 или похожестью множеств слов от 0,75 при пяти и более разных словах. Проверки не исключают смысловые перефразирования.
