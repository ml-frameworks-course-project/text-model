# Подборка текстов для разметки

Подборка содержит 150 примеров для ручного обогащения PromptShield. Разметчикам передаётся файл `annotation_input.jsonl` без исходных меток, чтобы каждый самостоятельно определил, содержит ли текст промпт-инъекцию.

Скрипт отбора создан 15 ноября 2026 года с помощью ИИ ChatGPT. В тот же день выборка пересобрана: добавлена проверка языка и исключены найденные смешанные тексты.

## Источники

- [NotInject](https://huggingface.co/datasets/leolee99/NotInject): 65 примеров; лицензия MIT; дата обращения: 15.11.2026.
- [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections): 53 примера из train; лицензия Apache-2.0; дата обращения: 15.11.2026.
- [LLMail-Inject](https://huggingface.co/datasets/microsoft/llmail-inject-challenge): 32 примера из первых 1000 записей Phase1, сценарий 1; лицензия MIT; дата обращения: 15.11.2026.

К письмам LLMail добавлена задача `Summarize all following emails.`. Остальные письма сценария в примеры не включены. Исходные идентификаторы и сведения о лицензиях находятся в `provenance_private.jsonl`.

До завершения независимой разметки не передавайте разметчикам `provenance_private.jsonl`, `selection_stats.json`, `stable_id_map.json` и `collect_candidates.py`. В них есть предварительные метки или параметры отбора. Итоговые метки определяются при ручной разметке.

## Воспроизведение

Для запуска нужны Python, пакеты `requests` и `langdetect==1.0.9`, а также доступ к Hugging Face:

```bash
pip install requests langdetect==1.0.9
python collect_candidates.py
```

Перед запуском измените переменную `OUT` в начале скрипта. Укажите путь к новой папке, которая ещё не существует: скрипт не перезаписывает существующую папку с результатами.

Язык определяется библиотекой `langdetect` с seed `52`. При ручной проверке обнаружены смешанные немецко-английские записи, которые исключены по номерам строк источника. Автоматическое определение языка может ошибаться, особенно на коротких и смешанных текстах. Таблица `stable_id_map.json` сохраняет идентификаторы ранее отобранных записей, которые остались в выборке.

При отборе использован seed `52` и предварительное соотношение классов 93 к 57. Версии источников и PromptShield указаны в переменной `SHAS`. PromptShield загружается по закреплённой версии, а остальные записи получаются через Dataset Viewer API. Если данные на сервере изменятся, повторный запуск может дать другой результат. Итоги отбора сохранены в `selection_stats.json`.

В обновлённой выборке 119 текстов сохранили прежние идентификаторы, для 31 идентификатора текст заменён. Ранее импортированные данные в doccano нужно обновить; уже сделанные ответы и заметки следует сохранить и сверить по `id` и полному тексту.

## Проверка пересечений

Точных совпадений и вхождений текстов длиной от 40 символов с train, validation и test PromptShield не обнаружено. Проверка не исключает перефразированные совпадения.
