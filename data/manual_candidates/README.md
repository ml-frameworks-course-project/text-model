# Подборка текстов для разметки

Подборка содержит 200 примеров для ручного обогащения PromptShield. Разметчикам передаётся файл `annotation_input.jsonl` без исходных меток, чтобы каждый самостоятельно определил, содержит ли текст промпт-инъекцию.

Скрипт отбора создан 15 ноября 2026 года с помощью ИИ ChatGPT. В тот же день выборка пересобрана: оставлены англоязычные тексты и усилена проверка похожих примеров.

## Источники

- [NotInject](https://huggingface.co/datasets/leolee99/NotInject): 87 примеров; лицензия MIT; дата обращения: 15.11.2026.
- [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections): 112 примеров из train и 1 пример из test; лицензия Apache-2.0; дата обращения: 15.11.2026.

Исходные идентификаторы и сведения о лицензиях находятся в `provenance_private.jsonl`.

До завершения независимой разметки не передавайте разметчикам `provenance_private.jsonl`, `selection_stats.json`, `stable_id_map.json` и `collect_candidates.py`. В них есть предварительные метки или параметры отбора. Итоговые метки определяются при ручной разметке.

## Воспроизведение

Для запуска нужны Python, пакеты `requests` и `langdetect==1.0.9`, а также доступ к Hugging Face:

```bash
pip install requests langdetect==1.0.9
python collect_candidates.py --output ./candidates_output
```

Запускайте команду из папки `data/manual_candidates`. В `--output` укажите путь к новой папке: скрипт не перезаписывает существующие результаты. Рядом со скриптом должен находиться `stable_id_map.json`.

Язык определяется библиотекой `langdetect` с seed `52`. При ручной проверке обнаружены смешанные и неанглоязычные записи, которые исключены по номерам строк источника. Записи с буквами нелатинских алфавитов также исключаются. Автоматическое определение языка может ошибаться, особенно на коротких и смешанных текстах. Файл `stable_id_map.json` содержит идентификаторы и хеши всех 200 текстов. Скрипт восстанавливает записи из источников и останавливается, если текст изменился.

При отборе использован seed `52` и предварительное соотношение классов 124 к 76. Версии источников и PromptShield указаны в переменной `SHAS`. PromptShield загружается по закреплённой версии, а остальные записи получаются через Dataset Viewer API. Скрипт проверяет ревизии этих источников до и после загрузки и останавливается, если они изменились. Итоги отбора сохранены в `selection_stats.json`.

Из прежних 150 текстов заменён только `TXT-149`. Новые примеры имеют идентификаторы `TXT-151`–`TXT-200`. Все 200 примеров находятся в одном файле `annotation_input.jsonl`. Перед обновлением doccano сохраните имеющийся экспорт и заметки; не загружайте полный файл повторно в проект с прежними записями, чтобы не создать дубли.

## Проверка пересечений

Скрипт проверяет совпадения с train, validation и test PromptShield по нормализованному тексту, вхождениям от 40 символов и похожести множеств слов от 0,75 для текста минимум с пятью разными словами. Также проверяется похожесть текстов внутри подборки. Бывший `TXT-149`, похожий на `TXT-031`, заменён; среди текущих 200 таких пар не обнаружено. Методы не исключают смысловые перефразирования.
